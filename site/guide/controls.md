# Controller and keyboard

Frame works with **PlayStation**, **Xbox** and **Steam** controllers out of the box, and shows a button guide that matches the one in your hands. Mouse and keyboard work everywhere too.

## Controller

| Button (PlayStation / Xbox) | Does |
|---|---|
| Cross / A | Select |
| Circle / B | Back. On Home and in libraries, goes back to the top first |
| Triangle / Y | Profile menu on Home · Info in the player · Join from an invite |
| Square / X | Delete a letter on the keyboard |
| L2 / R2 (LT / RT) | Previous / next tab (Home, libraries; seasons on a show page) |
| L1 / R1 (LB / RB) | Skip back 10 s / forward 30 s in the player · switch tabs in the player's panel |
| Options / Menu | Play / pause |
| Create / View | Full screen on or off |

## Keyboard

| Key | Does |
|---|---|
| Arrows | Move |
| Enter | Select |
| Escape | Back |
| Space | Play / pause |
| Page Up / Page Down | Previous / next tab |
| F11 | Full screen on or off |

## Mouse

Click anything; hover to select. In the player, click the bar to jump, and the mouse wheel skips back and forward.
