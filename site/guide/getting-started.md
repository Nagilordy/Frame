# Getting started

## 1. Install Frame

Download it from the [Download](/download) page and install it (Windows) or make it executable (Linux).

## 2. Connect to your server

The first time Frame opens, it asks **where your library is**. Pick your Jellyfin server if it shows up, or type its address (for example `192.168.1.20:8096`).

## 3. Sign in

On **Who's watching**, choose **Add profile**, then either:

- **Use your phone (easiest):** Frame shows a 6-digit code. In the Jellyfin app or website, open your profile, choose **Quick Connect** and enter the code.
- **Use a password:** type your Jellyfin user name and password with the on-screen keyboard (or a real one).

Frame remembers the profile on this computer, so next time it's one press.

::: tip Quick Connect
Quick Connect has to be turned on once in Jellyfin: **Dashboard → General → Quick Connect**.
:::

## 4. Watch

- **Home** shows your Continue watching (with the next episode ready), Recently added, and one tab per library (Movies, Shows, Anime…).
- Press **Play** or **Resume**. Frame plays the original file straight from your server, in the best quality your screen can show.
- During playback, bring up the bar to change **Audio**, **Subtitles** or **Playback**, or open **Info**.
