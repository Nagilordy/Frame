# Download

Frame is free. Get the latest version from the [Releases page on GitHub](https://github.com/Nagilordy/Frame/releases).

| System | File | How to install |
|---|---|---|
| **Windows 10 / 11** | `FrameSetup.exe` | Run it. Updates install over the old version, and your settings stay. |
| **Linux** | `Frame-x86_64.AppImage` | Make it executable (right-click → Properties → allow running as a program), then open it. |

On Linux, Frame downloads its own copy of mpv the first time it plays a video, for HDR and Dolby Vision. Nothing else to install.

::: tip Test builds
Versions marked **Pre-release** on GitHub are test builds: newest features, possibly rough edges. If you try one, [tell us what breaks](https://github.com/Nagilordy/Frame/issues/new?template=bug_report.yml).
:::

## What you need

- A **Jellyfin** server (10.9 or newer recommended), on your network or reachable over the internet.
- That's it. Sign in with your usual Jellyfin profile.
